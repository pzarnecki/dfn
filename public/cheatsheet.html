Docker — Ściągawka Komend

Podstawowe komendy

docker pull <obraz>

Pobiera obraz z rejestru (np. Docker Hub).

docker run <obraz>

Uruchamia nowy kontener na podstawie obrazu.

docker ps

Wyświetla listę uruchomionych kontenerów (-a pokazuje wszystkie).

docker stop <id>

Zatrzymuje uruchomiony kontener.

docker rm <id>

Usuwa zatrzymany kontener.

docker images

Wyświetla listę lokalnych obrazów.

Budowanie obrazów

docker build -t <nazwa> .

Buduje obraz z Dockerfile w obecnym katalogu.

FROM

Określa bazowy obraz (np. FROM ubuntu:20.04).

COPY <src> <dest>

Kopiuje pliki z hosta do kontenera.

RUN

Wykonuje polecenie podczas budowania obrazu.

EXPOSE

Informuje, na którym porcie nasłuchuje kontener.

CMD

Domyślne polecenie uruchamiane wraz z kontenerem.

Sieci i Wolumeny

docker network ls

Wyświetla listę sieci w Dockerze.

docker network create <nazwa>

Tworzy nową sieć.

docker volume create <nazwa>

Tworzy nowy wolumen.

-v <host_dir>:<container_dir>

Flaga (do docker run) podłączająca wolumen lub katalog z hosta (tzw. bind mount).

Docker Compose

docker compose up -d

Tworzy i uruchamia kontenery w tle (na podst. docker-compose.yml).

docker compose down

Zatrzymuje i usuwa kontenery, sieci i powiązane z nimi zasoby.

docker compose ps

Wyświetla kontenery zarządzane przez Compose.

Debugowanie

docker logs <id>

Wyświetla logi z kontenera (użyj -f by śledzić na bieżąco).

docker exec -it <id> bash

Otwiera interaktywną powłokę wewnątrz działającego kontenera.

docker inspect <id>

Zwraca szczegółowe informacje (JSON) o kontenerze lub obrazie.
